History & collection

Checking browser storage…

Your board scans. This tab collects.

The NanoC6 scans Bluetooth devices. API scan collection keeps history, matching, sorting, and signal analysis in this browser. Use Source to switch between live devices and browser history.

All live devices are retained. Browser history retains up to 10,000 older addresses and reports evictions. Address changes remain separate observations.

Keep the page open to collect data. Browsers reduce background polling; keep this tab visible for high-rate captures.

Storage belongs to this browser and address. Use nanoscope.local consistently; export and import history when switching to the hotspot address or another browser.

Recorder credentials are saved separately in browser local storage. Use Saved credentials to back up or restore recorder access.
